## 1. 当前痛点

### 1.1 现有流程

```
上传样例 → 分析结构 → 输入产品 → 点"生成脚本" → 自动渲染 → 播放视频
                                                    ↑
                                         用户什么都看不到就出片了
```

### 1.2 用户的问题

| 问题 | 表现 |
|------|------|
| **不可控** | "为什么这个分镜用原视频？为什么那个分镜用 AI？我能不能换？" |
| **不可见** | "AI 生成的提示词在哪？我能看看再决定要不要生成吗？" |
| **不透明** | "生成这个视频要花多少钱？用了多少 AI 调用？" |
| **不可逆** | "这个分镜的提示词不太好，但视频已经渲染完了，只能全部重来" |
| **不信任** | "系统给我生成了一个视频，但我不知道它是怎么决策的" |

## 3. 审核页面的信息架构

### 3.1 每个分镜卡片

```
┌─────────────────────────────────────────────────────────┐
│ 🟢 保留原素材                                   3.0s    │
│ ─────────────────────────────────────────────────────── │
│ 文案: "别再被电动车虚标动力骗了"                        │
│ 画面: 车标虚化转清晰                                   │
│ 来源: 原视频第 1 分镜                                   │
│                                                         │
│ [✏️ 改用 AI 生成]                                       │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 🟡 AI 生成 · Seedance                         4.0s       │
│ ─────────────────────────────────────────────────────── │
│ 文案: "为什么追我？太阳都追不上我"                       │
│                                                         │
│ ┌─ 提示词预览 ──────────────────────────────────────┐  │
│ │ 竖屏短视频画面，9:16构图：食品饮料类。             │  │
│ │ 旺仔牛奶红色铁罐特写，光滑金属表面反光...         │  │
│ │ 镜头语言: Cinematic slow push-in                  │  │
│ │ 后期处理: Clean photorealistic render             │  │
│ │ --ar 9:16 --style raw                             │  │
│ └──────────────────────────────────────────────────┘  │
│                                                         │
│ 🎥 运镜: 缓推  |  ✨ 特效: 无  |  😊 情绪: 亲切       │
│ 💰 预估: $0.03  |  ~120 tokens                         │
│                                                         │
│ [✏️ 编辑提示词]  [📋 复制到 Seedance]  [🔄 换用原素材] │
└─────────────────────────────────────────────────────────┘
```

### 3.2 审核操作

| 操作 | 说明 |
|------|------|
| **保留原素材** | 分镜使用原视频片段（默认，如果原视频有匹配内容） |
| **AI 生成** | 分镜使用 AI 生成的视频（默认，如果原视频无匹配内容） |
| **编辑提示词** | 用户可以修改 AI 生成的提示词文本 |
| **切换来源** | 任意分镜可以在"原素材"和"AI 生成"之间手动切换 |
| **预览卡片** | 点击展开提示词卡片的可视化预览（Pillow 渲染） |
| **复制到 Seedance** | 一键复制提示词，用户自己在 Seedance 里生成然后上传回来 |

### 3.3 成本面板

```
┌─────────────────────────────┐
```

## 4. 与现有页面的关系

### 4.1 现有页面保持不变

| 页面 | 变更 |
|------|------|
| 样例分析台 (AnalyzePage) | 不变 |
| 编辑结构 (MigratePage) | 不变 |
| 结果展示台 (ResultPage) | **改为此审核页面** |

### 4.2 ResultPage 改造

```
当前 ResultPage:
  自动渲染 → 视频播放器 → 评分指标 → 时间线

新 ResultPage:
  审核列表 → 成本面板 → [生成视频] 按钮 → 视频播放器 → 评分指标 → 时间线
```

### 4.3 数据流

```
MigratePage → 生成 FinalScript
    ↓
审核页面 ← 读取 FinalScript.segments
    ├── 有 asset_id 且 source=original → "保留原素材" 卡片
    ├── 无 asset_id 且 source=aigc    → "AI 生成" 卡片（展示提示词）
    └── source=packaging              → "包装补全" 卡片
    ↓
用户调整（切换来源、编辑提示词）
    ↓
POST /api/v1/render/{project_id} ← 带上用户编辑后的提示词
    ↓
compositor 渲染（AI 分镜用用户确认的提示词生成）
    ↓
视频播放器
```

## 5. 用户体验旅程

### 5.1 场景 A: 小白用户（第一次用）

1. 上传样例视频 → 等分析完成
2. 输入产品"旺仔牛奶" → 点生成脚本
3. 进入审核页 → 看到 5 个分镜，3 个标了"🟡 AI 生成"
4. 看到提示词已经写好了 → 点"一键生成视频"
5. 等待 1-2 分钟 → 播放完整视频
6. **感受**: "AI 帮我写好了提示词，我只需要确认一下就行"

### 5.2 场景 B: 专业用户（想精细控制）

1. 上传样例 → 分析 → 输入产品 → 生成脚本
2. 进入审核页 → 看到 5 个分镜
3. 点开 Hook 分镜的提示词 → 觉得不够好 → 点"编辑提示词"
4. 把"缓推"改成"快推"，加了一句"震屏特效"
5. 把 Product 分镜从"AI 生成"切换到"保留原素材"（因为自己有产品图想用）
6. 看到成本从 $0.17 变成 $0.12 → 满意
7. 点"一键生成视频"
8. **感受**: "系统给了我一个好的起点，我可以微调到满意"

### 5.3 场景 C: 零预算用户（无 API Key）

1. 上传样例 → 分析 → 输入产品 → 生成脚本
2. 进入审核页 → 所有分镜都是"🟡 AI 生成"但提示"无 API Key，将展示提示词卡片"
3. 看到提示词 → 点"导出全部提示词"
4. 拿到 TXT 文件 → 去 Seedance 网站逐个生成
5. 生成完回来 → 上传生成的视频片段作为素材
6. 再渲染一次 → 这次所有分镜都有素材了
7. **感受**: "即使不花钱，我也知道该怎么做了"

## 6. 技术实现要点

### 6.1 审核页数据结构

```typescript
interface ReviewSegment {
  id: string;
  type: SegmentType;
  script: string;
  duration: number;
  source: 'original' | 'aigc' | 'packaging';
  assetId: string | null;
  
  // AI 生成信息（source === 'aigc' 时填充）
  promptText: string;         // 完整提示词
  promptEnglish: string;      // Runway 版本
  promptChinese: string;      // Kling 版本
  camera: string;
  visualFx: string;
  estimatedCost: number;
  estimatedTokens: number;
  
  // 用户可编辑
  userEditedPrompt: string | null;  // 用户修改后的提示词
  userChosenSource: 'original' | 'aigc' | 'packaging';  // 用户手动选择
}
```

### 6.2 API 变更

```python
# 新增端点: 获取审核数据
GET /api/v1/review/{project_id}
→ { segments: ReviewSegment[], totalCost, aiCount }

# 修改端点: 渲染时接受用户编辑的提示词
POST /api/v1/render/{project_id}
body: {
  version, resolution,
  segment_overrides: [
    { segment_id, custom_prompt, source_override }
  ]
}
```

### 6.3 分阶段实现

| 阶段 | 内容 | 工时 |
|------|------|------|
| **Phase 1** | ResultPage 增加审核列表（只读，不可编辑） | 3h |
| **Phase 2** | 增加"编辑提示词"功能 + 来源切换 | 2h |
| **Phase 3** | 成本面板 + 预览卡片 | 2h |
| **Phase 4** | 渲染时使用用户编辑的提示词 | 2h |

## 7. 核心价值

> **从"AI 替你做决定"变成"AI 帮你做准备，你做决定"**

- 用户不再是黑盒的旁观者，而是决策者
- 提示词不再是导出后的后知后觉，而是审核中的核心信息
- 成本不再是意外的账单，而是可预期的投入
- 视频质量不再是一次性的赌博，而是可迭代的优化

这就是 Pixelle-Video "一句话生成视频"和 StructForge "结构迁移"之后的第三种范式：

**"AI 规划 + 人工审核 + 一键执行"**
