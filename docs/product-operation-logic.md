## 2. Phase A: 样例视频分析与结构拆解

### 2.1 触发方式

用户在 AnalyzePage 拖入 1-3 条 MP4 样例视频 → 前端 `POST /api/v1/analyze` (multipart/form-data) → 后端创建分析任务 → 前端轮询进度。

### 2.2 分析流水线 (AnalysisPipeline.run)

```
用户上传视频 (MP4)
        │
        ▼
┌──────────────────────────┐
│ Step 1: 媒体探测 (5%)    │  ffprobe 提取: 时长、分辨率、帧率、编码
│ probe_video()            │
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 2: 缓存检查          │  SHA-256 指纹(时长+分辨率+文件大小)
│ StructureCache           │  命中 → 直接返回缓存结果 (跳至 Step 8)
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 3: 场景检测 (25%)    │  PySceneDetect AdaptiveDetector
│ detect_scenes()          │  threshold=27, 检测镜头切换边界
│                          │  输出: [{start_ms, end_ms, duration_ms}]
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 4: 关键帧提取 (40%)  │  FFmpeg 在场景切换点提取 JPEG 帧
│ extract_keyframes()      │  最多60帧, 缩放至512px宽
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 5: 语音转写 (55%)    │  Volcano ASR BigModel API
│ transcribe_video()       │  两步流程: 提交任务 → 轮询结果
│                          │  输出: {text, segments[{start,end,text}]}
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 6: 视觉分析 (70%)    │  Doubao Vision 多模态模型
│ analyze_frames()         │  每帧分析: 场景类型、物体标签、情绪基调
│                          │  输出: {frames: [{tags, scene_type, ...}]}
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 7: LLM结构提取 (85%) │  Doubao Seed 2.0 Lite (3次重试)
│ extract_structure()      │  输入: meta+scenes+frames+ASR+Vision
│                          │  输出: VideoStructure (五维骨架)
└──────────┬───────────────┘
           ▼
┌──────────────────────────┐
│ Step 8: 后处理            │  封面生成 + 高光检测 + 镜头池构建
│ CoverGen + Highlight     │  缓存结果 + 绑定参考视频资产
└──────────────────────────┘
```

### 2.3 五维视频结构 (VideoStructure)

LLM 从视频中提取的核心数据结构，包含 5 个维度：

```
VideoStructure
├── meta (元信息)
│   ├── duration:   总时长 (秒)
│   ├── resolution: 分辨率 "1080x1920"
│   ├── shots:      镜头切换次数
│   └── coverLabel: 封面推荐文案
│
├── script (脚本/段落结构)  ← 任务2核心
│   └── ScriptSegment[] (3-8个分镜)
│       ├── id, type: hook|pain|product|proof|cta
│       ├── start, end, duration: 时间位置
│       ├── label: 段落标签 (例如 "开头吸引")
│       ├── copy: 该段落的文案/口播文本
│       ├── visual: 画面描述
│       ├── goal: 该段落要达到的心理目标
│       └── healthScore: 该分镜的健康度评分
│
├── rhythm (节奏结构)
│   └── RhythmPoint[] (秒级采样点)
│       ├── second: 时间点
│       ├── cuts: 该秒镜头切换次数
│       ├── emotion: 情绪强度 (0.0-1.0)
│       └── highlight: 是否高光时刻
│
├── packaging (包装结构)
│   ├── subtitleStyle: 字幕样式 (例如 "黄字白描边")
│   ├── transitions: 转场列表 ["硬切", "溶解", "左滑"]
│   └── overlays: 叠加元素 ["价格标签", "限时倒计时"]
│
└── health (健康度评估)  ← 5维雷达图
    ├── hook_strength:          开头吸引力 (0-100)
    ├── product_exposure_timing: 产品露出时机 (0-100)
    ├── selling_point_proof:     卖点证明力 (0-100)
    ├── pacing_compactness:      节奏紧凑度 (0-100)
    ├── cta_persuasiveness:      转化号召力 (0-100)
    └── overall:                 综合评分 (0-100)
```

### 2.4 评分详细标准

LLM 使用 5 级锚定标准对每个维度打分：

| 维度 | 90-100 (爆款级) | 70-89 (专业级) | 50-69 (合格) | 30-49 (较弱) | 0-29 (缺失) |
|------|----------------|---------------|-------------|-------------|------------|
| **开头吸引力** | 第1帧认知冲击，视听文协同 | 开头有效但可预测 | 套路化，老粉丝留新用户走 | 开头偏慢，文字先行 | 无Hook，注定失败 |
| **产品露出时机** | 3-5秒自然出场，不象广告 | 5-8秒专业展示 | 过晚或过早 | 几乎看不到产品 | 不知在卖什么 |
| **卖点证明力** | 无可辩驳的数据/对比 | 好的视觉支撑 | 泛泛描述，无区分度 | 纯断言，无证据 | 无卖点/虚假 |
| **节奏紧凑度** | 剪辑大师级，信息密而不压 | 节奏稳定，少数冗余 | 有明显拖沓 | 严重冗余或窒息的快 | 无节奏意识 |
| **转化号召力** | 具体指令+稀缺性+零风险+情感 | 明确的CTA | CTA存在但弱 | 模糊CTA | 无CTA |

### 2.5 在前端的可视化

分析完成后，AnalyzePage 展示 4 个 Tab：

| Tab | 组件 | 展示内容 |
|-----|------|---------|
| 脚本结构 | ScriptStructure | 横向比例卡片，每段显示类型+文案+时长占比 |
| 节奏结构 | RhythmStructure | AreaChart 面积图 — 情绪曲线 + 镜头切换频率 + 高光标记 |
| 包装结构 | PackagingStructure | 三列卡片 — 字幕样式 + 转场列表 + 叠加元素 |
| 健康度 | HealthRadar | RadarChart 五维雷达图 + 5 个分项 Badge |

## 3. Phase B: 结构迁移与脚本生成

### 3.1 触发方式

用户在 MigratePage 填写创作简报（产品名 + 卖点），选择生成风格，点击"生成视频脚本" → 前端 `POST /api/v1/migrate/{project_id}`。

### 3.2 迁移核心逻辑 (MigratorService.generate)

```
创作简报 + 样例结构 + 素材缺口 + 风格选择
        │
        ▼
┌──────────────────────────────────────┐
│ 1. 构建 LLM Prompt                   │
│    - 样例视频5维健康度评分            │
│    - 最薄弱的2个维度 (重点优化目标)    │
│    - 风格指令 (5种差异)               │
│    - 可用素材列表                     │
│    - 缺口信息                         │
│    - 约束条件 (时长/分镜数)            │
└──────────┬───────────────────────────┘
           ▼
┌──────────────────────────────────────┐
│ 2. LLM 生成 FinalScript              │
│    Doubao Seed 2.0 Lite (最多3次重试) │
│    每个分镜输出:                      │
│    - script: 口播文案                 │
│    - visual: 画面描述                 │
│    - 【镜】镜头运动 (快推/缓推/拉远…) │
│    - 【字】字幕动画 (弹入/淡入/逐字…) │
│    - 【速】语速 (快1.3x/正常/慢0.8x)  │
│    - 【情】语气 (惊讶/紧迫/亲切…)     │
│    - 【视】画面特效 (震屏/闪白/慢动作) │
└──────────┬───────────────────────────┘
           ▼
┌──────────────────────────────────────┐
│ 3. 后处理 (_normalize_script)        │
│    - 校验时长 (±10%容差)              │
│    - 绑定素材ID → 确定来源标签         │
│    - AI结构重排决策校验                │
│    - 转场推荐 (TransitionAdvisor)     │
│    - 叠加元素推荐 (OverlayAdvisor)    │
│    - 内容安全检查 (可选)               │
│    - LLM定性评审 (AI Review)          │
└──────────┬───────────────────────────┘
           ▼
┌──────────────────────────────────────┐
│ 4. 存储 + 版本管理                    │
│    - save_project_script()            │
│    - save_script_version()            │
│    - ResultEvaluator 评分             │
└──────────────────────────────────────┘
```

### 3.3 5种生成风格差异

| 风格 | 版本Key | Hook | 文案 | CTA | 字幕 | 转场 |
|------|---------|------|------|-----|------|------|
| 智能建议 | default | 保持原结构 | 专业清晰 | 温和引导 | 标准 | 硬切为主 |
| 高点击 | high_click | 更短更尖锐 | 冲击力强 | 紧迫 | 更醒目 | 快节奏 |
| 高转化 | high_conversion | 从痛点切入 | 强化信任 | 明确指令 | 突出价格 | 强调对比 |
| 快节奏 | fast_pace | 0.5秒即入 | 精简至极 | 闪电收尾 | 极简 | 紧凑 |
| 高质感 | high_quality | 氛围先行 | 精致克制 | 优雅引导 | 低调 | 平滑溶解 |

### 3.4 5参数制作体系 (镜/字/速/情/视)

LLM 在每个分镜的 `script` 字段末尾嵌入可执行制作参数：

| 参数 | 含义 | 可选值 |
|------|------|--------|
| 【镜】 | 镜头运动 | 静态 / 缓推 / 快推 / 拉远 / 横移 / 跟随 / 手持微晃 |
| 【字】 | 字幕动画 | 弹入 / 淡入 / 逐字出现 / 缩放出现 / 无动画 |
| 【速】 | 语速控制 | 快(1.3x) / 正常(1.0x) / 慢(0.8x) |
| 【情】 | 语气情感 | 惊讶 / 紧迫 / 亲切 / 权威 / 感动 / 兴奋 / 平静 |
| 【视】 | 画面特效 | 无 / 震屏 / 闪白 / 慢动作 / 放大 / 模糊过渡 |

> **注意**: 这些参数在渲染时会自动剥离，不会出现在最终字幕中。

### 3.5 来源溯源

每个分镜标注数据来源 (source 字段)：
- `original` — 用户上传的原创素材
- `reorder` — AI 重排后从其他位置调用的素材
- `packaging` — Pillow 生成的包装卡
- `aigc` — AI 生成的内容 (Seedream/Seedance)
- `recompose` — 从原视频裁切重组的片段

## 4. Phase C: 素材缺口检测与补全

### 4.1 缺口检测 (GapDetector)

```
当前视频结构 (3-8个分镜)
        │
        ▼
┌──────────────────────────────┐
│ 1. AssetMatcher 素材匹配      │
│    对每个分镜的 type+copy     │
│    与所有已上传素材做语义匹配  │
│    匹配分 < 60 → 不匹配        │
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│ 2. 识别缺口分镜               │
│    - 分镜无绑定素材           │
│    - 匹配分 < 60              │
│    → 标记为 gap               │
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│ 3. 分类严重度                 │
│    - critical: Hook / CTA    │
│      缺失 (致命)              │
│    - warning: 其他分镜        │
│      缺失 (需关注)            │
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│ 4. 推荐补全策略               │
│    每种策略标注 available     │
│    和最佳匹配策略             │
└──────────────────────────────┘
```

### 4.2 5种补全策略

| 策略ID | 名称 | 实现方式 | 可用条件 |
|--------|------|---------|---------|
| reorder | 结构重排 | AutoReorderService 算法最大化关键位置素材覆盖率 | 有匹配的素材 |
| packaging | 包装补全 | Pillow 生成 1080×1920 PNG 信息卡 (渐变背景+分段配色) | 始终可用 |
| aigc | AIGC 生成 | Seedream 生成封面图 / Seedance 生成视频片段 | API Key 已配置 |
| recompose | 素材重组 | FFmpeg 从原视频裁切片段，按 Vision 标签匹配 | 有视频素材 |
| reorder+packaging | 组合策略 | 先重排优化关键位置，其余用包装卡填充 | 有匹配素材 |

## 5. Phase D: 视频渲染与合成

### 5.1 触发方式

用户在 ResultPage 点击"导出视频" → `POST /api/v1/render/{project_id}` → 后端执行渲染 → 前端轮询进度 → 输出 MP4。

### 5.2 渲染流水线 (Compositor.render)

```
FinalScript + 素材 + 包装配置
        │
        ▼
┌──────────────────────────────────────────────┐
│ Phase 1: 逐分镜渲染 (10-70%)                  │
│                                              │
│ 对每个分镜 segment:                           │
│   ├─ 有用户素材 + 视频 → 裁切指定时间段       │
│   │   + Ken Burns 动态缩放效果               │
│   │   + ASS 字幕烧录                         │
│   ├─ 有用户素材 + 图片 → 静态图 + 缩放动画    │
│   │   + ASS 字幕烧录                         │
│   ├─ 参考视频 + 镜头池命中 → 裁切匹配片段     │
│   │   + 静音原音频 + ASS字幕                 │
│   ├─ 参考视频 + AI可生成 → Seedance文生视频   │
│   │   + 静音 + ASS字幕                       │
│   ├─ 参考视频兜底 → Pillow包装卡 (渐变背景)   │
│   │   + 分段专属配色 + ASS字幕               │
│   └─ 无素材 → 黑场占位 + ASS字幕             │
└──────────┬───────────────────────────────────┘
           ▼
┌──────────────────────────────────────────────┐
│ Phase 2: TTS 配音 (75%)                      │
│                                              │
│ Volcano SeedTTS SSE API                      │
│   全脚本 → 单次TTS合成 → 按分镜时长切分      │
│   → amix 混入每个分镜片段                    │
│                                              │
│ 若TTS不可用: 提示用户配置API Key              │
└──────────┬───────────────────────────────────┘
           ▼
┌──────────────────────────────────────────────┐
│ Phase 3: 动画叠加层 (80%)                     │
│                                              │
│ CTA / Hook 分镜:                             │
│   ├─ Remotion (优先): CTA弹簧动画/Hook弹跳    │
│   └─ Pillow (降级): fade_in_up/pop_in动画    │
│                                              │
│   叠加方式: overlay滤镜 + 透明通道WebM        │
└──────────┬───────────────────────────────────┘
           ▼
┌──────────────────────────────────────────────┐
│ Phase 4: 拼接合成 (85%)                       │
│                                              │
│ FFmpeg concat demuxer                        │
│   → 所有分镜按时间线顺序拼接                  │
│   → -c copy 无损流复制                       │
└──────────┬───────────────────────────────────┘
           ▼
┌──────────────────────────────────────────────┐
│ Phase 5: BGM 混音 (90-100%)                   │
│                                              │
│ 1. 检测可用BGM曲目 (bgm_library_dir)          │
│ 2. 无曲目 → 生成环境氛围音 (220Hz+330Hz)      │
│ 3. BGMEngine.mix_command()                   │
│    → amix 混合原音频+BGM                      │
│    → 自动处理无音轨视频 (anullsrc补静音轨)    │
│ 4. 输出: {project_id}/{version}.mp4           │
└──────────────────────────────────────────────┘
```

### 5.3 Ken Burns 动画效果

`build_video_command()` 按分镜类型应用不同的 FFmpeg zoompan 滤镜：

| 分镜类型 | 动画效果 |
|---------|---------|
| hook | 快速推近 zoom 1.0→1.08 |
| pain | 缓慢右移 + 微缩 (揭示语境) |
| product | 推近+微上移 (产品英雄镜头) |
| proof | 慢速水平扫描 + sin 振荡 (细节审视) |
| cta | 快速推近 zoom 1.0→1.10 + 下移 |

### 5.4 字幕渲染

- 格式: ASS (Advanced SubStation Alpha)
- 字体: Arial (可配置中文字体)
- 字号: 52px (高点击版 Hook 68px)
- 样式: 白字黑边, 底部居中
- 换行: >20字自动从中点断为两行
- **参数剥离**: `【镜】【字】【速】【情】【视】` 在字幕渲染前自动移除
