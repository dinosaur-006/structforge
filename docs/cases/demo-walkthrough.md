# StructForge 演示脚本（15分钟）

## 准备

```bash
# 1. 启动服务
docker compose up --build

# 2. 确认 demo 项目已创建（首次启动自动种子）
# 3. 打开浏览器：http://localhost
```

## 场景一：项目列表与 Demo 入口（1分钟）

1. 访问 `http://localhost` → 自动跳转到项目列表页
2. 展示已自动创建的 "StructForge Demo — 降噪耳机" 项目
3. 项目卡片显示状态、更新时间
4. 点击项目进入分析台

**展示要点**：一键启动，自动种子数据，零配置即可体验

## 场景二：样例分析与结构拆解（3分钟）

1. 分析台展示已完成的分析结果
2. **视频信息卡**：时长35s、分辨率1080x1920、12个镜头
3. **脚本结构**：5个叙事段落（Hook/Pain/Product/Proof/CTA），按比例可视化
4. 点击各段落查看详情：文案、视觉描述、健康度
5. **节奏结构**：AreaChart 展示镜头切换曲线，情绪峰值在18s
6. **包装结构**：字幕样式、转场类型、叠加元素
7. **健康度雷达图**：Hook 87、Pacing 81、CTA 39 → 综合72

**展示要点**：4类结构完整可视化，可解释可核查

## 场景三：素材上传与缺口诊断（3分钟）

1. 进入迁移台 → 已有4个 demo 素材
2. 展示素材面板：产品特写（图）、通勤场景（视频）、功能演示（视频）、卖点文案（文本）
3. 每个素材显示匹配分和推荐槽位
4. **缺口面板**：系统自动识别了N个缺口
5. 每个缺口显示严重程度、所需槽位、可用策略
6. **一键自动修复**：点击后系统自动选择最优策略补全缺口
7. 展示补全结果：生成的信息卡

**展示要点**：素材理解→匹配推荐→缺口识别→自动补全全链路

## 场景四：自然语言编辑（2分钟）

1. 点击时间线上方的 "自然语言编辑" 按钮（或 Ctrl+K）
2. 输入 "让开头更抓人一些，缩短Hook到2秒"
3. 系统调用 AI 修改结构：Hook 文案变短、时长调整为2秒
4. 时间线即时更新，Toast 显示变更摘要
5. 展示建议列表：点击 "把产品介绍提前"
6. 输入 "增加CTA的紧迫感，把优惠信息提到前面讲"
7. 撤销（Ctrl+Z）回退到之前状态

**展示要点**：人机协同，自然语言控制结构编辑

## 场景五：AI脚本生成与多版本对比（2分钟）

1. 选择风格："智能建议" / "高点击" / "快节奏" / "高转化" / "高质感"
2. 点击 "生成视频方案"
3. 自动跳转到结果页
4. **版本对比**：
   - 样例基线（结构分72） vs 高点击版（结构分XX）
5. **结构决策面板**：展示 AI 是否建议重排及原因
6. **指标对比**：素材覆盖率、产品首次露出、缺口数量、CTA时长
7. **双雷达图**：原始 vs 当前六维对比

**展示要点**：5版本风格策略，公式化评估可复现

## 场景六：视频渲染与导出（2分钟）

1. 打开导出对话框
2. 选择版本："原版" / "保守修复" / "Strong Hook" / "强转化"
3. 选择分辨率：1080p
4. 开始导出 → 查看渲染进度
5. 完成后下载 MP4 视频
6. 下载脚本 JSON 和 SRT 字幕文件

**展示要点**：生成→可视化→导出完整闭环

## 场景七：结构对比与融合（1分钟）

1. 回到分析台，展示多样例对比面板
2. 已有多条样例时，展示融合按钮（若已实现）
3. 展示不同样例的结构差异

**展示要点**：多样例支持，结构可对比

## 收尾（1分钟）

1. 总结四大核心能力：
   - 样例拆解（4类结构×可视化）
   - 素材补全（4策略×自动修复）
   - 结构迁移（5版本×规则评估）
   - 人机协同（NL编辑×手动调整）
2. 展示 `docs/cases/competition-checklist.md` 的赛题完成度

## 备用：技术架构说明

如果评审提问技术实现：
- **结构定义**：`VideoStructure` = meta + script + rhythm + packaging + health 五维骨架
- **迁移方式**：结构模板→素材匹配→缺口补全→LLM生成→规则评估
- **缺口策略**：包装(Pillow)/AIGC(即梦+回退)/重组(FFmpeg)/重排(AI算法)
- **可解释性**：来源追踪、决策面板、公式化评估
- **安全边界**：环境变量管理密钥、500MB上传限制、结构校验、内容安全审查
