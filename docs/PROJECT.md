# StructForge — 电商爆款视频结构迁移引擎

> 赛题: 爆款结构迁移引擎 | 赛道: 剪辑类/营销类 | 领域: 电商短视频

---

## 一、产品定位

StructForge 是一个专注于**电商带货短视频**的 AI 创作平台。它不是生成通用视频的工具，而是专为电商场景设计：从优质带货样例中提取经过验证的说服心理学结构，迁移到新商品上，生成可直接用于投放的短视频。

### 电商场景适配

| 设计决策 | 电商适配 |
|------|------|
| 5段叙事结构 | Hook→Pain→Product→Proof→CTA 带货标准结构 |
| 产品图视觉分析 | 上传商品图→Vision AI提取标签/颜色/纹理→注入生图提示词 |
| ComfyUI RunningHub | 云端GPU生成电商级产品照，无需自建集群 |
| LLM提示词工程 | 6层专业结构（构图/主体/灯光/环境/动作/技术），电商摄影级 |
| 素材缺口识别 | 检测Hook/Product/CTA等关键槽位是否缺素材 |
| 脚本风格 | 标准/高转化/高质感 3种电商场景 |
| 逐段生图/生视频 | 关键分镜可选WAN2.2视频，普通分镜用Flux图片 |

## 三、核心创新

### 3.1 视频"结构"定义

电商视频结构 = **5段说服心理学框架** × **5维制作参数**

```
Hook(3s) → Pain(5s) → Product(8s) → Proof(5s) → CTA(4s)
 快推       缓推         缓推          横移         快推
 弹入       淡入         缩放          逐字         缩放
 快         正常         正常          正常         快
 惊讶       亲切         兴奋          权威         紧迫
 震屏       无           放大          慢动作       放大
```

这些参数由 LLM 分析样例后**自主分配**，不是模板复制。

### 3.2 结构迁移方法

```
原视频结构骨架               新商品信息
┌────────────────┐         ┌──────────────┐
│ Hook→快节奏冲突  │         │ 趣多多曲奇     │
│ CTA→限时紧迫感  │   →    │ 真实巧克力豆   │
│ 5段 25秒       │         │ 趣味包装      │
└────────────────┘         └──────────────┘
              ↓
  LLM 迁移: 保持5段结构, 替换产品内容
  Flux 提示词: LLM生成6层专业电商摄影描述
  ComfyUI: 渲染8张产品照 → FFmpeg合成视频
```

### 3.3 素材缺口识别 & 补全

```
用户素材 vs 结构槽位:
┌────────┬────────┬────────┬────────┬────────┐
│ Hook❌  │ Pain❌  │Product✅│ Proof❌ │ CTA❌  │
└────────┴────────┴────────┴────────┴────────┘
         ↓ GapDetector 4策略推荐
  reorder → packaging → AIGC(ComfyUI) → recompose
         ↓ 实际渲染
  ComfyUI Flux 为所有缺失槽位生成 AI 画面
```

## 四、技术栈

| 层 | 技术 | 用途 |
|------|------|------|
| **前端** | React 18 + TypeScript + Vite + Tailwind + Zustand | SPA 7页面 |
| **后端** | Python 3.14 + FastAPI + Pydantic + SQLAlchemy | REST API |
| **LLM** | Doubao Seed (OpenAI-compatible) | 结构提取+脚本迁移+提示词 |
| **视觉** | Doubao Vision API | 产品图分析 |
| **图片** | RunningHub ComfyUI Flux | AI产品照生成 |
| **视频** | RunningHub WAN 2.2 | AI产品动画 |
| **语音** | Volcano ASR + Edge TTS | 转写+配音 |
| **视频处理** | FFmpeg + Pillow | 场景检测+合成 |
| **数据库** | SQLite | 嵌入式零配置 |

## 五、AI 工具使用声明

| 工具 | 用途 | 环节 |
|------|------|------|
| Doubao LLM | 视频结构提取、脚本迁移、Flux提示词 | 分析/迁移 |
| Doubao Vision | 产品图标签/颜色/OCR分析 | 分析 |
| RunningHub ComfyUI | Flux图像 + WAN视频生成 | 生成 |
| Edge TTS | 配音语音合成 | 生成 |
| Volcano ASR | 样例视频语音转写 | 分析 |
| FFmpeg | 场景检测/关键帧/视频合成 | 分析/生成 |
| Claude Code | 编码实现、架构优化、代码审查 | 开发 |

**自主设计**: 结构定义(5段框架+5维参数)、迁移方法(LLM prompt工程)、缺口检测算法(4策略引擎)、FluxPromptGenerator(6层专业提示词)、Swiss spa设计系统、全栈架构。

## 六、安全边界

1. API Key 仅存储在服务端 `.env`，前端不可见
2. 可选 `ContentSafetyService` 关键词拦截 LLM 脚本内容
3. 文件上传限制 500MB + 白名单类型检查
4. 所有数据本地 SQLite 存储，不上传第三方
5. 可选 `X-API-Key` 中间件保护后端
