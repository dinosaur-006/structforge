# 审核后生成模式 — 客观评估

> 日期: 2026-06-10

---

## 总体判断：方向正确，但要精简

这个改动把 StructForge 从"黑盒自动化"升级为"透明协作"。方向是对的——给用户控制权。但要避免过度设计。

---

## 一、真正的价值（3个）

### 1. 解决了"不知道 AI 干了什么"的信任问题 ⭐⭐⭐

**当前**: 用户点生成 → 等 2 分钟 → 看到一个视频。不知道哪些分镜是 AI 的、提示词是什么、为什么这么决策。

**改后**: 用户看到 5 张卡片，3 张 🟡 AI 生成，2 张 🟢 保留原素材。一眼就知道 AI 做了什么。

**价值**: 这是**信任基建**。比赛答辩时评委问"AI 怎么决策的"，用户可以直接打开审核页展示。

### 2. 给用户一个"救回来"的机会 ⭐⭐⭐

**当前**: 生成脚本 → 自动渲染 → 如果 LLM 把"旺仔牛奶"的提示词写成了"洗面奶"，用户只能在视频里看到一个错误的黑屏画面，然后全部重来。

**改后**: 审核页展示每个分镜的提示词 → 用户发现 Hook 段的提示词不对劲 → 点编辑修改 → 再生成。

**价值**: 把"重来成本"从 5 分钟降到 30 秒。

### 3. 零 API Key 用户终于有了一条完整的路径 ⭐⭐

**当前**: 无 API Key → 视频黑屏 → 只能通过导出按钮拿到提示词 → 但按钮不明显，用户找不到。

**改后**: 审核页直接展示所有提示词 → 每个卡片有"复制到 Seedance"按钮 → 用户复制 → 去 Seedance 生成 → 回来上传 → 再渲染。**整个流程是完整的、可理解的。**

**价值**: 让"我们没有 API Key"从产品缺陷变成产品特性。

---

## 二、过度设计的部分（2个）

### 1. "编辑提示词"功能 ⚠️

**问题**: 让用户在审核页编辑提示词文本，听起来很好，但实际上：
- 提示词是半结构化文本（中英混合、带技术参数），普通用户根本不知道怎么改
- 专业人士想改提示词，直接复制到 Seedance 里改更方便
- 增加复杂度：需要保存、撤销、校验编辑后的提示词

**建议**: **Phase 1 不做编辑**。只做展示 + 来源切换。编辑功能在 Phase 3 再考虑。

### 2. "成本面板" ⚠️

**问题**: 展示每个分镜的预估成本（$0.02、$0.03），看起来很专业，但实际上：
- 当前产品从不真正调用付费 API（用户无 Key），成本永远是 $0
- 即使有 Key，Seedance 的价格是固定的，用户无法控制
- 成本面板占空间，但对决策没有实际帮助

**建议**: **Phase 1 不做成本面板**。在"一键生成"按钮旁边放一个简单的 `💰 预估 $X.XX` 就够了。

---

## 三、实施建议：精简版

砍掉编辑和成本面板，只保留核心的"展示 + 切换 + 生成"：

```
┌─────────────────────────────────────────────┐
│          📋 审核与调优                        │
│                                              │
│  ┌─ Hook (3s) ──── 🟢 原素材 ──────────────┐ │
│  │ "别再被电动车虚标动力骗了"                │ │
│  │                          [🔄 改用 AI]     │ │
│  └──────────────────────────────────────────┘ │
│                                              │
│  ┌─ Pain (4s) ──── 🟡 AI 生成 ─────────────┐ │
│  │ 提示词: "旺仔牛奶特写，金属反光..."       │ │
│  │ 🎥 缓推 | ✨ 无 | 😊 亲切                │ │
│  │              [📋 复制提示词] [🔄 用原素材] │ │
│  └──────────────────────────────────────────┘ │
│                                              │
│  ┌─ CTA (3s) ──── 🟡 AI 生成 ─────────────┐ │
│  │ 提示词: "限时优惠，仅剩87单..."           │ │
│  │              [📋 复制提示词]               │ │
│  └──────────────────────────────────────────┘ │
│                                              │
│  💰 预估 $0.05（3个AI分镜）                   │
│  [🎬 生成视频]  [📥 导出全部提示词]           │
└─────────────────────────────────────────────┘
```

**只增加 3 个操作**：切换来源、复制提示词、生成视频。

---

## 四、与现有页面的关系

### 不是新建页面，是改造 ResultPage

```
当前 ResultPage:
  自动渲染 → 视频播放器 → 评分 → 时间线

改造后 ResultPage:
  ┌─ 审核列表（新增）─────────────────────┐
  │ 5 个分镜卡片，可切换来源               │
  │ [生成视频] 按钮                        │
  └────────────────────────────────────────┘
  ↓ 点击生成后
  ┌─ 原有内容（不变）─────────────────────┐
  │ 视频播放器 → 评分 → 时间线             │
  └────────────────────────────────────────┘
```

**不需要新建页面**。ResultPage 增加一个顶部区域即可。

## 五、风险

| 风险 | 严重度 | 缓解 |
|------|--------|------|
| 增加 ResultPage 复杂度 | 中 | 审核列表是可折叠的；生成后自动折叠 |
| 用户不知道怎么操作 | 低 | 🟢🟡 颜色 + 中文标签足够直觉 |
| LLM 还没成功生成脚本 | 中 | 审核页只在脚本生成后才显示 |
| 实施中有 Bug | 中 | 分 Phase 实施，每步测试 |
