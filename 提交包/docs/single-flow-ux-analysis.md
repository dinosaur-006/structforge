# StructForge 单一流程 UX 分析

> 从头到尾完整体验全产品，找出所有"多模式/多路径"造成的体验割裂  
> 设计唯一的最优单一路径  
> 不改代码，仅分析

---

## 零、当前用户完整旅程

```
项目页 → 分析台 → 编辑结构 → 结果页
  ↓         ↓         ↓          ↓
新建项目  上传视频  输入产品   审核+渲染
          AI分析   生成脚本   查看结果
```

---

## 一、每页的模式/路径分析

### 1.1 项目页 (ProjectListPage)

| 当前状态 | 问题 | 统一方案 |
|------|------|------|
| 新建项目弹窗可选填产品简报 | 用户可能跳过 → 后面编辑结构页还要再填一次 | 移除弹窗中的产品简报字段，只填项目名称。产品信息统一在编辑结构页填写 |
| 项目卡片点击跳转逻辑分叉：draft/analyzing → `/analyze`，其他 → `/migrate` | 用户不需要知道"状态路由" | 统一跳转到分析台，分析台自己判断是否需要重新分析 |

### 1.2 分析台 (AnalyzePage)

| 当前状态 | 问题 | 统一方案 |
|------|------|------|
| 单视频 vs 多样例两种上传 | 多样例是可选高级功能，UI 上却有多个上传入口 | 默认单视频上传，多样例作为折叠的"高级选项" |
| 分析完成后显示"继续"按钮 | 用户需要手动点击才能进入下一步 | 分析完成后自动跳转编辑结构页（或给出明显的 toast 提示） |
| 有"CapabilityStatusPanel" | 显示 LLM/ASR/AIGC 状态——普通用户看不懂 | 移到设置页，分析台不展示 |

### 1.3 编辑结构 (MigratePage)

| 当前状态 | 问题 | 统一方案 |
|------|------|------|
| 左侧结构预览 + 右侧产品简报 + 脚本风格 + NL编辑 + 素材上传 | 信息密度高，纵向滚动长 | ✅ 当前布局已经合理 |
| 7种风格选择（智能/高点击/高转化/快节奏/高质感/小红书/视频号） | 选择太多，用户决策困难 | 默认"智能建议"，其他收进折叠 |
| NL编辑输入框 | 用户不知道可以输入什么 | 增加 placeholder 示例 + 快捷指令标签 |
| 素材上传模块 | 可选但位置突出 | 收进折叠，默认隐藏 |
| "生成脚本"按钮 | ✅ 唯一的 CTA，好 | 保持 |

### 1.4 结果页 (ResultPage) — 最复杂的模式混乱

这是模式混乱的重灾区。当前 ResultPage 内部有 **4 层模式切换**：

```
reviewMode (useState)
  true  → 显示 ReviewPanel（审核分镜卡片）
  false → 显示 VideoPlayer（播放渲染结果）

version 选择
  切换不同版本的脚本（原始/高点击/高转化...）
  → 每切换一次，ReviewPanel 显示不同的 segments

compareMode (useState)
  true  → 并排对比模式
  false → 正常模式

historyOpen (useState)  
  true  → 侧边栏打开版本历史
  false → 关闭
```

**这 4 层模式让同一个页面有 2×N×2×2 种状态组合。** 用户完全不知道自己处于哪个状态。

#### 问题详解

| 模式 | 问题 |
|------|------|
| `reviewMode` | "审核模式"和"播放模式"是两个完全不同的界面。用户渲染完后看到视频播放器，想回去审核分镜——找不到路。 |
| `version 切换` | 用户可能在不同版本间反复切换，但不知道当前看到的是哪个版本的脚本。版本标签不够醒目。 |
| `compareMode` | 并排对比功能强大但入口隐蔽（一个小按钮），用户可能完全不知道存在。 |
| `historyOpen` | 版本历史从右侧滑入，覆盖了审核面板。用户可能不知道这是"历史"还是"当前"。 |

#### 统一方案

**取消 `reviewMode` 分叉。** 结果页永远同时展示两个区域：

```
┌─────────────────────────────────────────────────────┐
│  审核与生成                    [RENDER ALL]         │
│  11 个分镜 · 14.5s · 5 AI                            │
├──────────────────────────┬──────────────────────────┤
│                          │                          │
│  ReviewPanel             │  VideoPlayer             │
│  (分镜审核卡片)           │  (渲染结果/播放器)        │
│  - 每段卡片              │  - 视频播放               │
│  - 智能建议              │  - 分镜时间线             │
│  - 升级为视频            │  - 评分对比               │
│                          │                          │
├──────────────────────────┴──────────────────────────┤
│  脚本质量评估 · 渲染质量 · 规则量化得分                │
└─────────────────────────────────────────────────────┘
```

**渲染前**: VideoPlayer 区域显示 "点击 RENDER ALL 生成视频" 占位
**渲染后**: VideoPlayer 自动加载视频，ReviewPanel 保留在左侧

**取消 version 下拉切换。** 改为标签页：

```
[原始分析] [智能建议 ✓] [高点击] [高转化]
```

当前选中版本高亮，切换时 ReviewPanel 的 segments 联动更新。

**取消 `compareMode` 独立按钮。** 对比视图作为标签页的一个选项：

```
[分镜审核] [雷达对比] [时间线]
```

**取消 `historyOpen` 浮层。** 版本历史作为标签页的一部分，不遮挡主内容。

## 二、单一流程设计

### 唯一路径

```
项目页 → 分析台 → 编辑结构 → 结果页
  │         │         │          │
  │         │         │          └─ 一个页面完成：审核+渲染+播放+评分
  │         │         └─ 一个CTA：生成脚本
  │         └─ 一个CTA：分析视频（自动跳转下一步）
  └─ 一个CTA：新建项目（自动跳转分析台）
```

### 每页只有一件事

| 页面 | 唯一目标 | 唯一CTA | 自动流转 |
|------|------|:--:|:--:|
| 项目 | 查看/创建项目 | 新建项目 | → 分析台 |
| 分析台 | 分析参考视频 | 上传并分析 | → 编辑结构 |
| 编辑结构 | 输入产品+生成脚本 | 生成脚本 | → 结果页 |
| 结果页 | 审核+渲染+查看 | RENDER ALL | 渲染完成后自动展示结果 |

### 结果页的统一布局

```
┌─────────────────────────────────────────────────┐
│ WorkflowSteps  审核与生成                        │
├──────────────────────┬──────────────────────────┤
│ [标签: 分镜审核]     │  VideoPlayer             │
│                      │  (渲染前: 占位提示)       │
│ HOOK 1.3s AI        │  (渲染后: 播放视频)       │
│ 💡建议升级为视频      │                          │
│ [复制] [预览] [升级]  │                          │
│                      │                          │
│ PAIN 2s AI          │                          │
│ 静态图片已满足        │                          │
│ [复制] [预览] [升级]  │                          │
│ ...                  │                          │
├──────────────────────┴──────────────────────────┤
│ [标签: 质量评估]                                 │
│ 51项量化指标 · 参考基线64→预测78(+14)             │
│ 画面: ComfyUI Flux · 5/5段                       │
│ 配音: Edge TTS                                   │
├─────────────────────────────────────────────────┤
│ [标签: 分镜时间线]                                │
│ ResultTimeline                                   │
└─────────────────────────────────────────────────┘
```

## 三、关键UX改进点汇总

| # | 位置 | 当前问题 | 统一方案 |
|:--|------|------|------|
| 1 | 项目页 | 新建弹窗可选填产品简报 → 重复填写 | 弹窗只填项目名，产品信息统一在编辑结构页 |
| 2 | 分析台 | 分析完成后需手动点"继续" | 自动跳转编辑结构 |
| 3 | 分析台 | CapabilityStatusPanel 对普通用户无意义 | 移到设置页 |
| 4 | 编辑结构 | 7种风格选择太多 | 默认智能建议，其他折叠 |
| 5 | 编辑结构 | 素材上传可选但位置突出 | 折叠，默认隐藏 |
| 6 | 结果页 | reviewMode 分叉：审核/播放两个界面 | **取消分叉**，左右栏同时展示 |
| 7 | 结果页 | version 下拉切换 | **改为标签页**，当前版本高亮 |
| 8 | 结果页 | compareMode 按钮隐蔽 | **改为标签页** "雷达对比" |
| 9 | 结果页 | historyOpen 浮层遮挡 | **取消浮层**，内容内嵌 |
| 10 | 结果页 | 渲染后看不到审核面板 | 审核面板永远可见（左栏） |
