## 一、代码仓库 ✅

**地址**: https://github.com/dinosaur-006/structforge

**本地部署**:

```powershell
git clone https://github.com/dinosaur-006/structforge.git
cd structforge

# 后端
cd ai-services
copy .env.example .env          # 编辑 .env 填入 LLM + RunningHub API Key
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn main:app --host 0.0.0.0 --port 8000

# 前端（新终端）
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`
