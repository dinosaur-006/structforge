# StructForge 演示方案

> 演示时长: 8-10 分钟 | 建议使用电商食品/美妆类样例视频

---

## 一、准备工作

### 环境要求
- Python 3.14 + Node.js 18+
- Doubao LLM API Key (必需)
- RunningHub API Key (必需,用于AI画面生成)
- FFmpeg (必需)
- 后端: `cd ai-services && uvicorn main:app --port 8000`
- 前端: `npm run dev`

### 准备素材
1. **样例视频**: 1-2条电商带货短视频 (MP4, 15-45秒, 建议竖屏)
2. **产品图片**: 1张清晰的产品照 (JPG/PNG)
3. **产品信息**: 品牌名 + 3-5个核心卖点

---

## 二、演示流程

### Step 1: 上传样例视频 (1分钟)

**页面**: 分析台 (`/analyze`)

1. 拖拽或点击上传一条电商带货视频
2. 等待分析完成 (~60s)
   - 展示能力运行状态面板 (LLM/Vision/ASR/AIGC/Tasks)
   - 实时分析进度条
3. 分析完成 → 展示视频信息卡片:
   - 时长、分辨率、镜头数、封面标签
   - 结构标签页: 脚本结构 / 节奏结构 / 包装结构 / 健康度

**赛题对应**: 任务1 (样例解析) + 任务2 (3类结构拆解)

### Step 2: 输入产品信息 (1分钟)

**页面**: 编辑结构 (`/migrate/:id`)

1. 创作简报: 输入产品名称 + 卖点 (自动提取分析结果中的产品信息)
2. 上传产品图片 → Vision API 分析 → 展示识别标签
3. 素材缺口识别面板: 展示每个结构槽位的缺口状态和推荐策略
4. 可选: 自然语言调整 ("把开头改得更抓人")

**赛题对应**: 任务3 (素材输入+缺口识别) + 任务5 (缺口识别)

### Step 3: 生成脚本 (30秒)

1. 选择脚本风格 (标准/高转化/高质感)
2. 点击"生成视频脚本"
3. LLM 迁移: 保持原视频结构, 替换产品内容
4. 自动预生成每个分镜的 AI 提示词

**赛题对应**: 任务4 (结构迁移) + 任务10 (多版本)

### Step 4: 渲染视频 (3-5分钟)

**页面**: 结果展示台 (`/result/:id`)

1. Storyboard Review: 展示所有分镜的脚本/画面/运镜
2. 每个 AI 分镜可选择生成模式 (生图/生视频)
3. 点击 RENDER ALL → 实时进度展示
4. 渲染完成: 视频播放 + 时间线 + 结构对比

**演示要点**:
- 复制提示词按钮 → 展示 LLM 生成的 6 层专业提示词
- 渲染进度实时展示 (SSE推送)
- 时间线: 视频轨+字幕轨+音频波形

**赛题对应**: 任务4 (成片) + 任务6 (AIGC补全) + 任务7 (过程可视化)

### Step 5: 验证结果 (1分钟)

1. 播放生成的视频 (AI画面 + TTS配音 + 字幕)
2. 查看时间线 (分镜标注 AI/原始来源)
3. 导出脚本 JSON / 字幕 SRT
4. 版本对比 (切换不同风格版本)

**赛题对应**: 任务8 (结果可验证)

## 三、演示要点 (对着评审讲)

### 结构定义 (自创)
> "我们定义电商视频结构为 5 段说服心理学框架: Hook→Pain→Product→Proof→CTA。每段由 LLM 自主分配 5 个制作参数——镜头运动、字幕动画、语速、情感和画面特效。这不是模板复制,而是结构抽象。"

### 结构迁移 (自创)
> "迁移不是改写文案,而是把验证过的方法应用到新产品上。保持原视频的结构骨架,但所有内容——文案、画面描述、制作参数——都针对新产品重新生成。"

### 缺口处理 (自创)
> "当用户没提供素材时,系统自动检测 5 个结构槽位的缺口,推荐 4 种补全策略。实际渲染使用 ComfyUI Flux 为所有缺失槽位生成 AI 画面,用户上传了产品图还会用 Vision 分析结果优化提示词。"

### 提示词工程 (自创)
> "我们设计了一套 6 层专业提示词结构——构图、主体、灯光、环境、动作、技术参数——由 LLM 根据产品信息自动生成,生成的提示词包含具体的光比、镜头型号、材质描述,而非简单的'好物推荐'。"

## 四、Case 素材建议

准备 2-3 个电商案例演示:

| Case | 样例视频 | 产品 | 亮点 |
|------|------|------|------|
| 1 | 元气森林带货 (25s, 5段) | 趣多多巧克力曲奇 | 食品→食品完整迁移 |
| 2 | 美妆产品展示 (20s) | 珂润洗面奶 | 品类迁移+产品图视觉分析 |
| 3 | 数码产品开箱 (30s) | 蓝牙耳机 | AI视频(WAN2.2) 演示 |

每个 Case 保留:
- 样例分析结果截图
- 迁移后的脚本对比
- AI生成的提示词
- 最终视频产物 (MP4)
