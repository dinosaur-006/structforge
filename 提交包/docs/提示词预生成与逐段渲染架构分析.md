## 当前流程

```
用户生成脚本 → 进入结果页
  → Storyboard Review 展示每个分镜 (脚本 + 参数 + 提示词)
  → 每个 AI 分镜可选择: [🖼 生图] [🎬 生视频]
  → 点击"生成 N 图 + M 视频"
  → 渲染管道: LLM 提示词 → Flux 图片 → [可选] WAN 2.2 视频
  → SSE 推送进度 → 完成 → 播放
```

## 降级链

```
提示词: LLM (Doubao) → fallback: PromptEngine 规则引擎
图片:   ComfyUI Flux (1080p原图) → fallback: Pillow 蓝图卡
视频:   WAN 2.2 (512x288) → fallback: Flux 静态图 + FFmpeg 运镜
```
